# GoidaLauncher

Оффлайн-лаунчер Minecraft на C# / WPF, .NET 10.0. Работает без входа через
Microsoft (пиратский режим) — ник вводится вручную.

## Возможности

- Единое окно с вкладками вверху: **Играть · Версии · Моды · Скин · Настройки**.
- Вкладка **"Версии"** — установка новой сборки: загрузчик слева
  (Vanilla/Fabric/Quilt/Forge), версии посередине, уже скачанные отмечены ✓.
- Вкладка **"Играть"** показывает только то, что уже установлено, одним
  списком с явным загрузчиком в названии: `1.20.4 (Vanilla)`,
  `1.20.4 (Fabric)`, `26.2 (Forge)` — без путаницы, какая есть какая.
- Загрузчики модов:
  - **Fabric** и **Quilt** — полностью автоматически через официальные Meta API.
  - **Forge** — тоже автоматически: лаунчер скачивает установщик и сам
    прогоняет официальную цепочку установки (install_profile.json + processors),
    как это делает родной инсталлятор. Это самая сложная часть лаунчера — если
    что-то пойдёт не так на конкретной версии, лог покажет, на каком шаге.
- **Каждая сборка (версия+загрузчик) изолирована** — свои `mods/`, `config/`,
  `saves/`, `resourcepacks/`. Моды одной сборки никогда не мешают другой.
- **Свои скины** — вкладка "Скин": загружаете PNG, он подключается ко всем
  установленным сборкам автоматически (без официального аккаунта — см. ниже).
- Моды и текстурпаки прямо из **Modrinth** — поиск и установка в один клик,
  качаются сразу в папку той сборки, что выбрана на "Играть".
- Настройки: память, путь к Java, доп. параметры JVM, папка игры,
  Discord Rich Presence, акцентный цвет интерфейса.
- Лог процесса скачивания и вывод консоли игры прямо в окне лаунчера.

## Требования

- **Visual Studio 2022** (17.12+) с workload **.NET desktop development**
- **.NET SDK 10.0**
- Установленная **Java** — версия зависит от версии Minecraft (1.20.5+ → Java 21,
  1.17–1.20.4 → Java 17, 1.12–1.16 → Java 8). Путь к ней указывается в
  настройках, либо лаунчер найдёт `javaw.exe`/`java.exe` в PATH сам.

## Как открыть и собрать

```
GoidaLauncher.sln → открыть в Visual Studio → F5
```

Либо через консоль:

```
dotnet build
dotnet run --project GoidaLauncher
```

### Как собрать exe, чтобы отправить друзьям

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый файл: `bin\Release\net10.0-windows\win-x64\publish\GoidaLauncher.exe` —
один файл, .NET-рантайм зашит внутрь, другу ничего доустанавливать не нужно.
Java у него всё равно должна быть установлена отдельно — лаунчер её не носит.

## Как работают скины без официального аккаунта

Без покупки Minecraft: Java Edition игра не может выдать вам "настоящий" скин
с серверов Mojang — офлайн-игрок всегда рисуется дефолтным Steve/Alex.
Ресурспак, который **переопределяет** текстуру Steve/Alex на ваше изображение,
работает поверх этого и превращает "болванку" в кастомный скин — это
легальный и рабочий способ, которым пользуются многие оффлайн-лаунчеры.
Ограничение: скин будет виден **только вам самим** (для остальных игроков
на сервере вы всё ещё Steve/Alex, если у них нет такого же пака).

## Про Forge — если что-то пошло не так

В отличие от Fabric, у Forge нет простого JSON-профиля — официальный
установщик патчит байткод отдельными Java-процессами ("processors"), и
именно эту цепочку лаунчер воспроизводит. Формат задокументирован, но
может отличаться в деталях между версиями Forge. Если установка упадёт —
лог покажет номер шага и хвост вывода Java с ошибкой; пришлите этот текст,
разберём вместе, что пошло не так на конкретной версии.

## Структура проекта

```
GoidaLauncher.sln
GoidaLauncher/
  App.xaml / App.xaml.cs        — тема оформления, акцентный цвет
  MainWindow.xaml / .cs         — главное окно
  SettingsWindow.xaml / .cs     — окно настроек
  ModrinthWindow.xaml / .cs     — браузер модов/текстурпаков Modrinth
  TextInputWindow.xaml / .cs    — компактное окно ввода текста (профили, скины)
  Models/
    VersionManifest.cs          — список версий + сортировка/разделитель
    VersionDetails.cs           — client.json конкретной версии
    AssetIndex.cs                — индекс ассетов
    LauncherProfile.cs           — настройки лаунчера
    GameProfile.cs                — сохранённый профиль версии+загрузчика
    FabricModels.cs / ForgeModels.cs / ModrinthModels.cs
  Services/
    MinecraftService.cs          — скачивание файлов игры и запуск процесса
    FabricService.cs             — интеграция с Fabric Meta API
    ForgeService.cs              — установка Forge (install_profile + processors)
    ModrinthService.cs           — поиск/скачивание модов и текстурпаков
    SkinService.cs                — генерация ресурспака со скином
    SettingsService.cs / ProfilesService.cs — сохранение настроек/профилей
    RuleEvaluator.cs              — фильтрация библиотек по правилам ОС
```

Данные игры: `%AppData%\GoidaLauncher\minecraft`
Настройки: `%AppData%\GoidaLauncher\settings.json`
Изолированные сборки: `%AppData%\GoidaLauncher\minecraft\instances\<версия-загрузчик>\`
Скины: `%AppData%\GoidaLauncher\minecraft\skins\`

## Изоляция сборок (mods/config/saves/resourcepacks)

Каждая установленная сборка (версия + загрузчик, например "1.20.4 (Fabric)"
и "1.20.4 (Forge)") имеет **свою отдельную** папку под `instances/` —
со своими `mods/`, `config/`, `saves/`, `resourcepacks/`, `shaderpacks/`.
Моды одной сборки никогда не попадают в другую, миры не путаются между
разными наборами модов. Сами версии/библиотеки/ассеты остаются общими —
их незачем дублировать, они не конфликтуют.

Кнопка 📁 в шапке и кнопка "Установить" на странице Modrinth всегда работают
с папкой **той сборки, что выбрана на вкладке "Играть"** прямо сейчас.

## Скины

Файл скина хранится один раз в общей папке `skins/`, а при каждом запуске
игры автоматически копируется в `resourcepacks/` той сборки, которую вы
запускаете — так что скин работает одинаково во всех сборках без ручной
настройки на каждой. Технически: ресурспак переопределяет текстуры всех
девяти дефолтных скинов Minecraft (Steve, Alex, Ari, Efe, Kai, Makena, Noor,
Sunny, Zuri) — офлайн-игроку один из них назначается по хэшу UUID, заранее
не угадать какой, поэтому переопределяются сразу все.

## Discord Rich Presence

Показывает в статусе Discord "Играет в Minecraft 1.20.4 (Fabric) — через
GoidaLauncher". Работает через нативный IPC-протокол Discord, без стороннего
NuGet-пакета.

Нужен свой Application ID — в отличие от Microsoft, это займёт 1 минуту без
всякой модерации:
1. Зайдите на https://discord.com/developers/applications → **New Application**.
2. Дайте любое имя, создайте.
3. На вкладке **General Information** скопируйте **Application ID**.
4. Вставьте его в настройках лаунчера → раздел Discord.

Если Discord не запущен на компьютере — лаунчер просто не покажет статус,
без ошибок и без блокировки запуска игры.

## История ников

Поле "Никнейм" запоминает последние 8 введённых ников и предлагает их в
выпадающем списке — полезно, если играете под разными именами.

## Доп. параметры запуска

В настройках есть поле "Доп. параметры запуска (JVM)" — всё, что там
написано, добавляется в конец списка Java-флагов при каждом запуске
(например `-XX:+UseZGC`).

## Пасхалки

Клик по логотипу GOIDA открывает один из трёх видео в браузере.
Клик по питомцу слева — тоже кое-что делает. Остальное ищите сами. 🥚
